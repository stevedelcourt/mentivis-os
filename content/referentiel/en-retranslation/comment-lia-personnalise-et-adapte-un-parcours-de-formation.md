> AI personalises a learning path in three stages: an initial diagnostic that measures what the learner has actually acquired, the generation of a learning path built specifically for their profile (rather than selected from a catalogue), and the continuous recalculation of that path at each assessment. This personalisation is not cosmetic: it applies to the content itself, its order, its difficulty and its assessments. It is fundamentally different from the personalisation through predefined conditional paths offered by most conventional LMSs.

### The fundamental distinction: generation versus selection

Almost every platform describes its features as "personalised". In most cases, this personalisation consists of filtering an existing catalogue according to the user's profile, or offering conditional paths defined in advance. This is fixed branching: the paths have been planned, and the algorithm selects which one to follow.

Personalisation through generation is different. The system does not select from an existing catalogue: it produces the content, exercises and assessments specific to the learner's profile, based on a skills framework.

### The initial diagnostic

Before generating a learning path, the system needs to know what the learner already knows. Without this information, personalisation is superficial: the interface or the pace may be adapted, but not the content.

The diagnostic can take several forms: an assessment questionnaire at the start of the learning path, analysis of existing data in the HRIS, or a combination of the two. The quality of the diagnostic directly determines the quality of the personalisation.

### Generating the learning path

On the basis of the diagnostic and the defined objectives, the system generates an individualised learning path: modules in a suitable order, a format appropriate to the type of content, and assessments calibrated to the current level.

This learning path is not the same for two learners with the same objective. Someone who has already mastered the fundamentals starts further along the path. Someone with a gap in a prerequisite must close that gap first.

### Continuous recalculation

At each assessment built into the learning path, the system measures what has actually been acquired and recalculates what comes next.

If a skill has been mastered, the system moves on. If a gap persists or reveals another one, the learning path adjusts. If a skill that appeared to have been acquired reveals a gap during a delayed assessment, the system schedules spaced review.

This continuous recalculation is what distinguishes an adaptive system from an LMS with conditional paths.

### What this changes for the learner

Training time is reduced because the learner does not go through content they have already mastered. Within documented scopes, studies observe a 20 to 40% reduction in training time for an equivalent level of acquisition.

Engagement is stronger because the content is calibrated to the actual level. Progress is visible skill by skill, rather than as an abstract percentage.

### Limitations to be aware of

AI personalisation depends entirely on the quality of the skills framework and the data available. It does not resolve problems of engagement and motivation linked to the organisational context.

### Frequently asked questions

**Can a conventional LMS personalise?**
It can offer conditional paths defined in advance. This is not dynamic personalisation: it is fixed branching, in which every path has been planned by an instructional designer.

**Is the adaptation visible to the learner?**
It can be, through a dashboard showing progress skill by skill. In any case it is felt: an adapted learning path is perceived as more relevant and less repetitive.

**How long before a difference can be seen?**
Studies on adaptive learning observe measurable effects after 3 to 4 weeks of regular use, provided the initial diagnostic is well constructed.
